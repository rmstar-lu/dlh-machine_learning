
# Optimization

## `0-l2_reg_cost.py`

A function that calculates the cost of a neural network with L2 regularization.

## `1-l2_reg_gradient_descent.py`

A function that updates the weights and biases of a neural network using gradient descent with L2 regularization.

## `2-l2_reg_cost.py`

A function that calculates the cost of a neural network with L2 regularization as a tensor.

## `3-l2_reg_create_layer.py`

A function that creates a neural network layer in tensorFlow that includes L2 regularization.

## `4-dropout_forward_prop.py`

A function that conducts forward propagation using Dropout.

## `5-dropout_gradient_descent.py`

A function that updates the weights and biases on a neural network using gradient descent with Dropout regularization.

## `7-early_stopping.py`

A function that determines if you should stop gradient descent early.
