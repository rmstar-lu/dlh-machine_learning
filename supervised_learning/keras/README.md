
# Keras

## `0-sequential.py`

A function that builds a NN with the Keras library.

## `1-input.py`

A function that builds a NN with the Keras library using the functional API.

## `2-optimize.py`

A function that sets up Adam optimization for a keras model with categorical
crossentropy loss and accuracy metrics.

## `3-one_hot.py`

A function that converts a label vector into a one-hot matrix using K.utils.

## `4-train.py`

A function that trains a model using mini-batch gradient descent.

## `5-train.py`

Same function with validation data.

## `6-train.py`

Same function with early stopping option.

## `7-train.py`

Same function with inverse time decay on learning rate option.

## `8-train.py`

Same function with save best iteration of the model option.

## `9-model.py`

Functions to save and load an entire model.

## `10-weights.py`

Functions to save and load a model's weights.

## `11-config.py`

Functions to save and load a model's configuration in JSON format.
