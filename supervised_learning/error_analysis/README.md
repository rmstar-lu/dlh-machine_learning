
# Error analysis

## `0-create_confusion.py`

A function that creates a confusion matrix.

## `1-sensitivity.py`

A function that calculates the sensitivity for each class in a confusion matrix.

## `2-precision.py`

A function that calculates the precision for each class in a confusion matrix.

## `3-specificity.py`

A function that calculates the specificity for each class in a confusion matrix.

## `4-f1_score.py`

A function that calculates the F1 score for each class in a confusion matrix.
